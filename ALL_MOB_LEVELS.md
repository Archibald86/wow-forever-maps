# All mob levels by default

NPC positions and the level heat map are enabled by default without a level
filter. A one-time saved-settings migration clears legacy level, role, type,
search and service filters while preserving the selected zone and character
level. Subsequent user choices still persist; explicit shared URL filters remain
supported. Recommendation links no longer force the -2..0 level restriction.

The Show all mobs button enables both mob layers and clears their level/type/
role/search/service filters. Changing character level recolors the heat map
without hiding levels when the optional level filter is off. Source coverage
and NPC grouping remain unchanged; showing all available records is not a
claim of exhaustive or live population coverage.
