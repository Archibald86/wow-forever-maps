# Этап 4 — ресурсы, навыки, предпочтения и учителя

## Реализовано

### Подсказки и справочник

Справочник содержит 42 типа ресурсов, встречающихся на текущих картах:
15 типов руды и 27 трав. Названия и идентификаторы сверены с предоставленным
GatherMate2/Constants.lua; русские названия взяты из его локализации Vanilla.
Снимки файлов, исходная лицензия и GPL-2.0 сохранены в sources/gathermate/.

При наведении на ресурс появляется краткая подсказка. Нажатие или выбор
в списке показывает название, координаты, профессию, минимальный навык,
источник требований и дату справочника. Историческое происхождение
координат и непроверенное игровое совмещение явно обозначены.

Список точек выбранной области доступен с клавиатуры. Выбор ресурсов
не меняет смысл выбранной ячейки плотности мобов.

### Фильтры

- Конкретный ресурс либо все ресурсы.
- Горное дело и травничество по эффективному навыку с учётом бонусов (0–400).
- Применение порога навыка включается отдельно.
- Неизвестные требования показываются или скрываются отдельной настройкой.
- Все фильтры сохраняются и передаются по ссылке наравне с прежними настройками.
- Пустой результат фильтра отличён от отсутствия записей в исходнике.

Порог известен по справочнику для 41 из 42 типов. Для ароматитовой жилы
(GatherMate ID 219) требование оставлено неизвестным: доступные сведения
нашлись в комментариях, а подтверждения в основной таблице не получено.
Это значение не заменено предположением. Специальное оборудование,
позволяющее сбор без профессии, фильтр автоматически не учитывает.

### Предпочтения фарма

Четыре режима с явным правилом сортировки:

1. **Мобы и ресурсы рядом:** сначала сумма индексов подходящих ячеек, затем
   число подходящих точек руды и трав рядом с ними.
2. **Мобы:** сумма индексов подходящих ячеек.
3. **Руда:** число подходящих исторических записей руды в локации.
4. **Травы:** число подходящих исторических записей трав в локации.

Для сбора ресурсов локации без данных мобов сохраняются в выдаче с явной
пометкой. Отсутствие таблицы мобов не считается признаком безопасности.
Результаты содержат фактические количества записей, без выдуманного
XP/hour, доходности или взвешенного «коэффициента эффективности».
Переход на карту передаёт ресурс, навыки, режим и нужные слои.

## Дополнительный слой

Добавлены 35 записей учителей: 15 горного дела и 20 травничества на имеющихся
картах. Лиловый квадрат обозначает учителя. Доступен фильтр Альянса/Орды,
включающий нейтральных учителей. Конкретный ресурс ограничивает список
учителей соответствующей профессией.

Для каждого учителя сохранены имя, координаты, профессия, фракция,
ограничение начальным рангом, где оно указано, и источник. На острове
Зефрас доступны четыре записи. Это справочная выборка, не полный список
учителей мира. Города и другие территории без карт в текущем атласе
не импортировались.

## Источники и проверка данных

- [WoWhead Forever: Mining](https://www.wowhead.com/forever/guide/professions/mining/overview-leveling)
  — таблица требований и координаты учителей горного дела.
- [WoWhead Forever: Herbalism](https://www.wowhead.com/forever/guide/professions/herbalism/overview-leveling)
  — таблица требований и координаты учителей травничества.

Обе страницы указывают обновление 2026-11-09 и патч 1.60.1. Сведения
сверены 2026-11-14. Сохранены компактные факты и атрибуция, без копирования
текста статей. Справочные требования не подменяют проверку в игровом клиенте.

В частности, для истинного серебра используется порог 230, а для малой
ториевой жилы 245 из таблицы Forever; значения не перенесены по памяти из
другой версии игры. Исходные координаты руды и трав не изменены.

Канонические дополнения: sources/resource_catalog.json и trainers.json.
Новые входы включены в sources/build_inputs.json с SHA-256. Полная сборка
остаётся воспроизводимой и не требует сети:

```sh
python tools/build_data.py
python tools/build_data.py --check
python -m unittest discover -s tests -v
node tests/core.cjs
node tests/settings.cjs
node tests/resources.cjs
```

## Проверки

- 148 проверок геометрии: все 37 карт на четырёх ширинах.
- 128 комбинаций слоёв и фильтра мобов в двух режимах, включая учителей.
- Сохранены 86 функциональных сценариев этапа 2 и 14 сценариев этапа 3.
- 13 сценариев этапа 4: навык на границе порога, конкретный ресурс,
  неизвестный порог, сохранение фильтров, учителя и фракции, сбор ресурсов
  при отсутствии данных мобов, пустая выдача, передача фильтров на карту,
  мобильная геометрия и отдельная эмуляция touch-нажатия.
- Проверяются отказ от неверных метаданных, детерминированная сборка,
  контрольные суммы входов и сохранность прежних координат.
- Новые проверки включены в процесс публикации до развёртывания.

## Ограничения

Игровое совмещение координат, реальные спавны и доступность маршрутов
не проверялись в клиенте. Требование навыка одного ресурса неизвестно.
Слой учителей неполный и основан на датированном справочнике. Интерфейс
проверяется в Chromium с эмуляцией размеров экрана и touch-событий;
реальные телефоны, Firefox и Safari отдельно не проверялись.
