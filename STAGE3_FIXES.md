# Этап 3 — удобство, читаемость и воспроизводимая сборка

## Настройки

- Сохраняются локация, уровень, пять переключателей и режим отображения.
- Приоритет: явно заданные параметры ссылки → сохранённые настройки →
  значения по умолчанию. Неверные локации и режимы игнорируются, уровень
  нормализуется по общим правилам 1–60.
- Состояние записывается в URL без создания лишних шагов истории и в
  localStorage. При недоступном хранилище сайт продолжает работать через URL.
- Уровень согласован между главной страницей и атласом. Рекомендации
  по-прежнему передают свою локацию, уровень и фильтр −2…0.
- Кнопка копирования ссылки передаёт все настройки. Если Clipboard API
  недоступен, ссылка появляется в выделенном поле для ручного копирования.
- Кнопка сброса восстанавливает настройки по умолчанию.

## Плотность и легенда

- По умолчанию мобы показаны полупрозрачными ячейками 5% × 5%.
  Цвет означает разницу уровней, насыщенность — индекс плотности в пределах
  исходного набора (1–50), а не количество одновременно живых мобов.
- Прежний режим условных точек доступен в переключателе отображения.
  Для Болота Печали вместо 7 677 условных точек можно рисовать 215 ячеек.
- Когда ячейка меньше 24 × 18 CSS-пикселей, числа автоматически скрываются.
  Нажатие показывает уровень и индекс выбранной ячейки. Доступны стрелки
  клавиатуры и Escape; информация выводится обычным текстом с role=status.
- Легенда содержит все 12 диапазонов/значений: ≤−8, −7…−5, −4…+4, ≥+5.
  Серый порог по-прежнему предварительный и не определяет получение опыта.
- Объяснены все обозначения ресурсов: голубой круг — медь, золотой —
  другая руда, зелёный ромб — травы. Соответствие Copper Vein → 201
  проверено по предоставленному GatherMate2/Constants.lua.
  SHA-256 исходного GatherMate2(1).7z:
  `dc4f779e35ca6f403b0634c977d9fc4a112d44da319c17700673a666cd939ce4`.
- Исправлена читаемость градиентного слова «Азерота» на главной странице.

## Воспроизводимая сборка

В репозитории сохранены входные файлы, необходимые для сборки:

- `sources/gathermate/MiningData.lua`, `HerbalismData.lua` и формат источника;
- `sources/mob_cells.csv` — прежняя таблица оценочных ячеек;
- `sources/zones.json` и `zone_mapping.json` — каталог и сопоставления;
- `sources/build_inputs.json` — SHA-256 зафиксированных исходников.

Полная сборка не читает существующий data.json и не требует сети или
установки дополнительных Python-пакетов:

```sh
python tools/build_data.py
python tools/build_data.py --check
python -m unittest discover -s tests -v
```

Можно собрать в пустую папку:

```sh
python tools/build_data.py --output /tmp/wow-data
```

Из тех же входных файлов получаются побайтово одинаковые data.json,
data.js, coverage.json и манифесты. Изменённый исходник или устаревший
экспорт останавливает проверку. `sources/build_manifest.json` содержит
контрольные суммы входов и результатов. Полная проверка включена в CI
до публикации сайта.

Все значения данных этапа 2 сохранены: 37 карт, 4 066 ячеек мобов,
4 511 записей руды и 9 319 записей трав. Формула рекомендаций не изменена.

## Проверки

- 148 проверок геометрии: 37 карт × 4 ширины экрана.
- 64 комбинации переключателей: по 32 в режимах ячеек и точек.
- Сохранены проверки этапа 2: все 60 уровней и восемь сбоев данных
  с восстановлением, всего 86 функциональных сценариев.
- 14 сценариев этапа 3: восстановление, приоритет URL, перенос настроек
  в новый браузерный контекст, копирование с запасным вариантом, сброс,
  полная легенда, оба режима, выбор ячейки на телефоне и с клавиатуры,
  общий уровень страниц, повреждённое и заблокированное хранилище.
- Две независимые сборки сравниваются побайтово; изменение исходного
  файла намеренно проверяется как ошибка.

## Ограничения

Игровое совмещение координат и реальные спавны не проверены. Происхождение
самой оценки плотности остаётся унаследованным от предоставленной таблицы.
Проверки интерфейса выполнены в Chromium; отдельные Safari и Firefox
не проверялись. Локальные исходники и прежние версии сохранены.
