# Квесты в подсказках мобов

Наведение показывает число уникальных квестов: прямое убийство и добыча обязательных предметов. При выборе точки видны ID квестов и ограничения данных.

Прямые убийства берутся из положительных целей CMaNGOS Classic без ReqSpellCast и сверяются с NPC-целями Questie Forever. Специальные взаимодействия Questie (лечение и подобные действия) исключаются. Добыча связывается через обязательные предметы квеста и npcDrops в Questie Forever. Не учитываются выдача/сдача квеста, начало задания выпавшим предметом и произвольные текстовые упоминания.

Один квест учитывается один раз для каждого NPC, даже если требует несколько его предметов. При совпадении убийства и добычи квест относится к убийствам. Для альтернатив на одной точке используется объединение ID без повторов.

Это справочные связи, не активный журнал персонажа: фракция, класс, цепочки, фазы и доступность не проверены. Ноль означает отсутствие записей в источниках. Наличие предмета у моба не означает, что убийство именно этого вида обязательно: возможны другие источники.

Индекс mob-quest-data.js воспроизводится tools/build_mob_quests.py при запуске tools/build_data.py. Исходные снимки и условия: sources/questie/NOTICE.md и sources/classic_spawns/WORLD_NOTICE.md.
