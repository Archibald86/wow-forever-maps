# Уровни зон

Источник: Leatrix Maps 1.60.31, Interface 16001 (Forever), Leatrix_Maps/Leatrix_Maps.lua, таблица mapTable в разделе ShowZoneLevels (строки 7420–7490). Проверено 16.11.2026 по пользовательскому архиву WoW_Forever_Master_Database_v2_ADDON_PACK.zip, вложенный файл originals/Leatrix_Maps.zip.

SHA-256 вложенного архива: 35156def482867f50c999d3889c3371b83925f69d14430020189e0977bd5c6f4.

В подписях используются числовые рекомендации автора аддона. Это не уровни отдельных квестов, не диапазон всех мобов и не ограничение входа. Сопоставление выполнено по UI Map ID из sources/zone_mapping.json.

Для 39 классических карт в таблице есть диапазоны; ещё один есть для Zephras Isle (UI Map ID 2521): 1–12. Для Moonglade (1450) указано только рыболовство, поэтому диапазон персонажа не выводится. Darkspearisland (2524) отсутствует в таблице. Оба случая отображаются как «уровни уточняются».

Исправления относительно прежнего справочника Classic: Красногорье 15–25, Тлеющее ущелье 43–50, Зимние Ключи 55–60. Остальные 36 диапазонов классических зон совпадают.

Список карт разделён на Калимдор (18 классических зон) и Восточные королевства (22). Привязка проверена по world_map_id в sources/classic_spawns/config-world.json. Внутри группы сортировка по нижней границе уровня, затем верхней, затем названию; зоны без диапазона стоят в конце. Два отдельных острова Forever сохранены в своей группе без предположения об их континенте. ID карт, ссылки и выбор зоны сохраняются.
