# Mob Level Map numeric reference data

Source: Noise Code / noisecodes, Mob Level Map 1.0.7, released 2026-11-14.
https://www.curseforge.com/wow/addons/mob-levels/files/9605623

The addon page is marked All Rights Reserved. No blanket GPL/MIT license or
redistribution permission is asserted. This reference pack records numeric
cell values and source provenance; it does not include the addon's Lua code,
textures or a reimplementation of its XP model. Keep this attribution and the
original version/hash metadata with derived records.

The continent base data is a Classic Era reference. ForeverOverrides are
identified separately as author-described Forever scan corrections. Primary
scan observations and the base-table generation method were not supplied.
The index is not a verified live mob count. Individual spawn coordinates,
hostility, respawn rates, floors and current layer population are not supplied.
