# Этап 2 — данные ресурсов и основные функции

## Реализовано

- Подключены 568 ранее пропущенных записей руды: Хилсбрад (UiMapID 1424,
  141 запись), Когтистые горы (1442, 133) и остров Зефрас (2521, 294).
  Всего в текущей версии 4 511 записей руды.
- Подключены 9 319 исторических записей трав для существующих карт,
  включая 628 записей острова Зефрас. Переключатель «Травы» управляет
  зелёными ромбами независимо от слоя мобов и фильтра их уровней.
- Все слои рисуются одной функцией. Изменение руды, плотности, уровня,
  фильтра или локации больше не теряет включённый слой трав.
- Обе страницы округляют дробный уровень до ближайшего целого, затем
  ограничивают его диапазоном 1–60. Пустые и нечисловые значения дают 42;
  0 даёт 1, 42.5 даёт 43. Числовое поле, ползунок, URL перехода и расчёт
  используют одно значение.
- На сайте данные загружаются как JSON с проверкой структуры. Сетевой
  сбой, HTTP-ошибка, повреждённый JSON или неполная структура показывают
  понятное сообщение и кнопку повторной загрузки. Недоступные действия
  блокируются до успешной загрузки. При открытии файлов напрямую остаётся
  поддержка data.js.
- Ошибка загрузки отдельной карты сохраняется при переключении слоёв;
  выбор другой карты восстанавливает работу.
- Для всех 37 локаций опубликовано coverage.json. Отсутствие данных мобов
  отделено от отсутствия записей ресурсов в исходнике; последнее не означает
  отсутствия ресурсов в игре. Счётчики на главной рассчитываются из данных.

## Источники и воспроизводимость

Источник ресурсов: предоставленный пользователем `GatherMate2_Data(1).zip`,
файлы `GatherMate2_Data/forever/MiningData.lua` и `HerbalismData.lua`.
SHA-256 архива: `997fbc101c6c1bb43fd42c38562f4625f1f7e713385a955161c07f75350abe51`.

Сопоставления UiMapID проверены по предоставленному QuestieDB:
`QuestieDB/support/Forever/Zones/uiMapIdToAreaId.lua`.
Идентификаторы и контрольная сумма этого архива записаны в
`sources/zone_mapping.json`. Данные Questie о NPC/квестах не импортируются.

Все координаты независимо сверены с исходными ключами XXXXYYYY00 при
точности сайта до двух знаков. Все существовавшие записи руды и ячейки
мобов сохранены. У пяти карт, где нет таблицы мобов, теперь явно задан
пустой массив без выдуманных значений.

Для каждой локации и слоя `sources/resource_import_manifest.json` содержит
число записей и SHA-256. В data.json сохранены пути исходных файлов,
их контрольные суммы, статус исторических наблюдений и статус проверки
картографического совмещения.

Повторный импорт из корня репозитория:

```sh
python tools/import_resources.py --source /path/to/GatherMate2_Data.zip --site-root .
python -m unittest discover -s tests -v
node tests/core.cjs
```

## Проверки

- Все 37 карт на ширинах 320, 390, 768 и 1440 px: 148 проверок геометрии.
- 32 комбинации переключателей слоёв и фильтра.
- Подбор мест для всех 60 уровней.
- Сохранение трав при изменении слоёв, уровня и локации.
- Восемь сценариев сбоя данных и восстановления: обе страницы при сетевом
  сбое, повреждённом JSON, неполной структуре и HTTP 500.
- Дробные, пустые, нечисловые и выходящие за диапазон уровни.
- Ошибка загрузки изображения и восстановление выбором другой карты.
- Эти проверки входят в workflow публикации GitHub Pages.

## Ограничения

Координаты ресурсов — исторические записи GatherMate2, а не гарантированные
спавны. Проверены декодирование, принадлежность к UiMapID и работа интерфейса.
Совмещение с реальным игровым миром Forever не проверялось. Конвертация
Era → Forever не добавлена, чтобы не преобразовать уже подготовленные данные
повторно. Локации без изображений в текущем атласе не добавляются.

Архив базы v3.1 сохраняет прежнее покрытие и остаётся историческим результатом
этапа 1. Новый импорт ресурсов не изменяет его содержимое.
