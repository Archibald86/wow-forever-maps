Ресурсы, навыки и предпочтения фарма

Укажите навык с учётом бонусов. Специальные предметы, позволяющие собирать без профессии, не учитываются. Пороги из справочника Forever; точки исторические.

Для мобов учитываем уровень персонажа и на 1–2 ниже. Для сбора ресурсов сортируем по количеству подходящих записей в локации; данные мобов показываем справочно. В смешанном режиме сначала сравниваем плотность мобов, затем число ресурсов рядом. Индекс плотности — относительный показатель, а не число живых мобов. Руда — исторические данные GatherMate2. Это рекомендации по локациям, не проверенные маршруты фарма.
