# Источники и план развития WoW Forever Maps
Проверено: 2026-11-14. Не смешивать Classic Era и Forever без проверки карт/ID/координат.

## Первая очередь
1. **QuestieDB Forever** — https://github.com/Questie/QuestieDB/blob/master/docs/forever.md
   - отдельные Forever-данные по квестам, NPC, коррекциям и картам;
   - применять строго Forever ID / coordinate conversion, проводить аудит совпадений;
   - учитывать условия отдельных файлов и неоднородные исторические права; см. sources/questie/NOTICE.md.
2. **GatherMate2_Data** — https://www.wowace.com/projects/gathermate2_data
   - узлы Mining/Herbalism/Fishing/прочее; официальное описание указывает на поддержку Forever;
   - импортировать отдельно от исторических исходников; сохранить provenance, дату и тип узла;
   - не считать узлы гарантированным спавном.
3. **Wowhead Forever database** — https://www.wowhead.com/forever/database
   - предметы, объекты, NPC, квесты, зоны, профессии, рудные жилы;
   - справочник для ID/уровней/навыков; НЕ массово копировать контент без проверки условий использования.
4. **AzerDex** — https://azerdex.com/
   - наблюдательные данные по мобам/добыче/траве/руде/рыбалке;
   - небольшая выборка (на 2026-11-09: 5 зон), показатели не равны гарантированным вероятностям;
   - проверить лицензию/наличие API перед импортом.

## Дополнительные источники
- Blizzard Forever — https://worldofwarcraft.blizzard.com/en-us/forever/ — первичный источник изменений мира и дизайна; использовать как визуальный ориентир, не копировать логотипы/ассеты автоматически.
- Официальный пресс-центр — https://blizzard.gamespress.com/wowforeverreveal — пресс-материалы, условия использования и разрешения проверять отдельно.
- Руководство по добыче в Forever — https://www.wowhead.com/forever/guide/professions/mining/overview-leveling — навыки, новые предметы и требования.

## Первоначальный технический план (актуальное состояние ниже)
1. Создать нормализованные слои данных: zones, mobs, resource_nodes, quests, items, vendors. Для каждой записи: game_flavor, source, source_date, source_id, confidence.
2. Сопоставить ID локаций с Forever UiMap; не переносить координаты Classic без конвертации и аудита.
3. Разделить реальные наблюдения и оценочные тепловые ячейки мобов; показывать разные обозначения.
4. Добавить в атлас переключатели Mining / Herbalism / Fishing / Quests и легенду, когда появятся данные.
5. Добавить tooltips: название узла, необходимый навык, источник/дата, точность.
6. Для ТОП-5 добавить настраиваемые приоритеты «мобы / руда / травы», но не называть оценочный балл XP/hour.
7. Покрыть тестами все картографические ID, наличие jpg, валидность координат 0–100 и допустимые уровни.

- Круг вокруг нажатия, радиус 2/5/10/20% ширины карты, таблица по NPC ID.
- Точные повторы одного ID и координат удаляются; разные ID в одной позиции сохраняются.

- Число живых существ, таймеры и враждебность не выводятся из количества записей.
- Данные источников сохранены; подробности и проверки: NPC_AREA.md.
